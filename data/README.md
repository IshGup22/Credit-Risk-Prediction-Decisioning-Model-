# Data

This project uses the **Default of Credit Card Clients** dataset from the UCI Machine Learning Repository.

## Source

Yeh, I. (2009). Default of Credit Card Clients. UCI Machine Learning Repository.

Dataset:
https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

## Dataset Description

The dataset contains 30,000 credit card client records from Taiwan.

It includes information on:

- Credit limits
- Demographic characteristics
- Repayment status
- Monthly bill amounts
- Monthly payment amounts
- Default payment status

The target variable indicates whether a client defaulted on their payment.

## Raw Data

The original dataset is distributed by the UCI Machine Learning Repository as:

`default of credit card clients.xls`

The dataset is used for educational and portfolio purposes with attribution to the original source.
