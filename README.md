# Credit Risk Prediction

A machine learning project that analyzes customer credit data and predicts the likelihood of credit card default.

## Project Overview

Financial institutions need to assess the likelihood that a customer may fail to meet future payment obligations. This project explores historical customer and payment information to identify patterns associated with credit default and build classification models for predicting default risk.

The project will include data exploration, preprocessing, feature analysis, machine learning model development, and model evaluation.

## Objectives

- Explore customer demographic, credit, and repayment data
- Identify patterns associated with credit default
- Clean and preprocess the dataset for machine learning
- Build and compare classification models
- Evaluate model performance using appropriate classification metrics
- Interpret the factors that contribute to credit risk

## Machine Learning Models

The project will compare multiple classification approaches, including:

- Logistic Regression
- Decision Tree

Additional models may be explored if they provide useful comparison.

## Model Evaluation

Models will be evaluated using metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## Dataset

This project uses the **Default of Credit Card Clients** dataset from the UCI Machine Learning Repository.

The dataset contains information about credit limits, customer characteristics, repayment history, bill amounts, payment amounts, and credit default outcomes.

Dataset source:

https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
